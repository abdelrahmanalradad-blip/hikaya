# حكايا | Hikaya 📖
تطبيق روايات وكتب عربي (قراءة + كتابة + لوحة تحكم + إشعارات).
**Backend:** Cloudflare Workers + D1 (قاعدة البيانات) + R2 (الصور) — **التطبيق:** Capacitor → APK بيتبني على GitHub Actions.

## المميزات
- **القارئ:** رئيسية بأقسام، بحث وفلاتر، مكتبة، سجل قراءة، متابعة من آخر نقطة، إعجاب، تقييم، تعليقات، بلاغات، متابعة الكتّاب، مشاركة.
- **القراءة:** حجم الخط والتباعد، خطين، أربع خلفيات، قراءة صوتية، قائمة فصول، حفظ التقدم.
- **الكاتب:** نشر روايات، غلاف، فصول (مسودة/منشور)، ترتيب الفصول.
- **الإشعارات:** فصل جديد في رواية بمكتبتك أو لكاتب بتتابعه، تعليق جديد على روايتك، اعتماد/رفض روايتك، وإشعارات عامة من الأدمن. + صفحة إشعارات داخل التطبيق.
- **الأدمن:** إحصائيات، اعتماد/رفض/تمييز/إخفاء/حذف الروايات، المستخدمين (ترقية/حظر/تغيير كلمة مرور)، التصنيفات، التعليقات، البلاغات، إرسال إشعار للجميع، إعلان وإعدادات.

## الإعداد (مرة واحدة)

### 1) Cloudflare
1. سجّل في https://dash.cloudflare.com (مجاني). من **Workers & Pages** افتح الصفحة مرة واحدة عشان يتفعّل عنوان `workers.dev` الخاص بحسابك.
2. من **R2 Object Storage** فعّله (بيطلب بيانات دفع للتفعيل لكن الاستخدام الصغير مجاني).
3. انسخ **Account ID** (من الصفحة الرئيسية للحساب أو الشريط الجانبي).
4. اعمل **API Token**: My Profile → API Tokens → Create Token → قالب **Edit Cloudflare Workers**، وزوّد له صلاحية **Account → D1 → Edit** لو مش موجودة.

### 2) Firebase (للإشعارات فقط — مجاني)
1. https://console.firebase.google.com → Add project.
2. Add app → **Android** → Package name بالظبط: `com.hikaya.app` → نزّل `google-services.json`.
3. Project settings → **Service accounts** → *Generate new private key* → ملف JSON.

### 3) GitHub
ارفع المشروع كله (مع فولدر `.github`) على Repo جديد، وبعدين **Settings → Secrets and variables → Actions** وضيف:

| Secret | القيمة |
|---|---|
| `CLOUDFLARE_API_TOKEN` | التوكن من الخطوة 1 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID |
| `JWT_SECRET` | أي نص عشوائي طويل (32+ حرف) — متغيّرهوش بعد كده |
| `GOOGLE_SERVICES_JSON` | **محتوى** ملف google-services.json كله |
| `FCM_SERVICE_ACCOUNT` | **محتوى** ملف الـ Service Account JSON كله |
| `ADMIN_EMAIL` | (اختياري) إيميلك — أي حساب بالإيميل ده يبقى أدمن |

لو ما حطيتش `ADMIN_EMAIL` أول حساب يتسجل بيبقى هو الأدمن.
لو سبت `GOOGLE_SERVICES_JSON` أو `FCM_SERVICE_ACCOUNT` فاضيين التطبيق يشتغل عادي بدون إشعارات.

### 4) البناء
أول ما ترفع الملفات الـ Workflow بيشتغل: ينشر الـ API وينشئ قاعدة البيانات، وبعدها يبني الـ APK.
حمّل `Hikaya.apk` من **Releases** وثبّته. سجّل أول حساب (= الأدمن) وهتلاقي **لوحة التحكم** في تبويب "حسابي".

## ملاحظات
- الـ APK **debug-signed**: يتثبت مباشرة. للنشر على Google Play محتاج توقيع Release.
- مفيش استرجاع كلمة مرور بالإيميل (محتاج خدمة إيميل). الأدمن يقدر يغيّر كلمة مرور أي مستخدم من لوحة التحكم.
- الإشعارات بتشتغل على أندرويد فقط، وأندرويد 13+ هيسأل المستخدم عن الإذن أول مرة.
- لو الـ API URL اتغيّر يدوياً ضيف سر `API_URL`.
- تشغيل الـ API محلياً: `cd worker && npm install && npx wrangler dev`.
